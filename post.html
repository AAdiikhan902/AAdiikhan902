# The Blue Carpet — starter news site A ready-to-deploy news website built with Jekyll, made for free hosting on GitHub Pages. ## 1. Put this on GitHub 1. Create a new repository on GitHub named exactly `yourusername.github.io` (swap in your real username). Public, no README (you already have one here). 2. Upload every file in this folder to that repository, keeping the folder structure intact (the `_posts`, `_layouts`, `assets` folders must stay as-is). - Easiest way: on the repo page, click **Add file → Upload files**, then drag this whole folder's contents in. 3. Go to **Settings → Pages** and confirm the source is set to the `main` branch, root folder. (For a `username.github.io` repo this is usually automatic.) 4. Wait 1–2 minutes, then visit `https://yourusername.github.io`. ## 2. Customize it - **Site name / tagline / nav categories** — edit `_config.yml`. - **About page** — edit `about.md`. - **Colors and fonts** — edit `assets/css/style.css` (the palette and fonts are defined as CSS variables and imports at the top). ## 3. Publish a story Add a new file to `_posts/`, named: ``` _posts/YYYY-MM-DD-your-headline-slug.md ``` With this front matter at the top: ```markdown --- title: "Your Headline" category: World dek: "One-sentence summary shown under the headline." author: Your Name --- Your article text in Markdown goes here. ``` `category` must be one of the names in `nav_categories` in `_config.yml` (World, Politics, Business, Technology, Sports, Opinion) for it to show up on that category page — or add your own categories to the config. The newest post automatically becomes the homepage lead story; older posts fill the grid and the "Latest on the wire" sidebar. ## 4. Remove the sample posts Delete the three files already in `_posts/` (`welcome-to-the-desk.md`, `second-sample-story.md`, `third-sample-story.md`) once you're ready to publish real stories. ## Notes - No build step needed — GitHub Pages runs Jekyll for you automatically on every commit. - `jekyll-feed` gives you an RSS feed at `/feed.xml` for free. - Everything is plain HTML/CSS/Markdown, so it's safe to hand-edit any file directly on GitHub's website — no local install required.
